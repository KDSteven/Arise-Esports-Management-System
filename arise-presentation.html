System Overview ARISE MIS
What is the ARISE MIS?
A centralized management platform built for the ARISE Esports student organization
🎯

Purpose

Digitize and streamline all organizational operations — from member onboarding to certificate issuance — eliminating manual, paper-based processes.

👥

Users

Designed for 5 officer roles: Admin, President, Treasurer, Secretary, and Auditor. Each role sees only what they need.

📋

Coverage

10 functional modules covering Members, Events, Finances, Certificates, Tasks, Officers, Reports, Activity Logs, and Database Management.

🌐

Accessibility

Fully web-based — accessible from any modern browser on any device. Includes a public landing page for prospective members to apply online.

Security Architecture ARISE MIS
Multi-Layer Security
Designed to prevent unauthorized access, brute-force attacks, and data injection

🔐 Authentication

  • JWT tokens (7-day expiry)
  • Bcrypt password hashing
  • OTP-based password reset
  • Auto-logout on 401 response
  • lastLoginAt tracking

🛡️ Brute-Force Protection

  • Rate limiter: 10 attempts / 15 min (login)
  • Rate limiter: 5 requests / hour (password reset)
  • Account lockout after 5 failed logins
  • 30-minute lockout duration
  • 429 & 423 responses with clear messages

🧱 Server Hardening

  • Helmet.js security headers
  • CORS restricted to CLIENT_URL
  • express-mongo-sanitize (NoSQL injection)
  • Input validation via express-validator
  • Role middleware on every protected route
🔒
